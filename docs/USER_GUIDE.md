# 安装与使用

## 适用设备

本版本验证机型：Sony A6300，固件 2.01。其他型号尚未完成验收。需要可正常读写的 SD 卡和充足电量。

## 安装 APK

1. 下载发行页中的 `SonyLutCamera-v0.9.0-beta.3.apk`（发行页尚未提供 APK 时，表示该包仍在发布准备中）。
2. 拔掉 USB，在相机 `MENU → 设置 → USB 连接` 选择 **MTP**，再用数据线连接电脑。
3. 用 [Sony-PMCA-RE 的 App Installer](https://github.com/ma1co/Sony-PMCA-RE#app-installer) 选择下载的 APK 安装。命令行示例：

   ```sh
   python pmca-console.py install -f /path/to/SonyLutCamera-v0.9.0-beta.3.apk
   ```

   连接后相机菜单可能不可操作；需要改 USB 模式时先拔线。在 macOS 上，照片、图像捕捉等程序可能占用 MTP 连接，先退出它们。不要把普通安装与固件更新／服务模式操作混用。
4. 安装器确认成功后断开 USB，进入 `MENU → 应用程序 → 应用程序列表 → LUT Camera`。

已安装同签名版本可以直接覆盖更新，原有 LUT 和照片保留。签名不匹配时不要通过清空应用数据或格式化 SD 卡解决，先核对 APK 来源。普通使用不用安装开发用“测试连接”。

## 第一次拍摄

首次打开自动加入「示例调色」和「原色」，可能需要等待数秒；后续打开复用已有资源。上下键／拨轮选 LUT，右侧参考照片显示对应效果，中央键进入拍摄。

应用为所选 LUT 自动生成近似取景参数。出现差异提示时，选「继续使用近似预览」或「使用原色取景拍摄」；这项选择不改变最终完整 LUT 调色。

半按完成对焦，再全按拍摄。半按时暂时显示原色属于当前设计，用于隔离预览参数与成片。等待保存完成后查看成片，半按返回取景。应用保留两张 24MP EXTRA FINE JPEG，分别为原片与调色成片。

左右键／拨轮调整亮度（曝光补偿），中央键归零；DISP 切换信息显示。

## 导入自己的 LUT

1. 将独立 3D `.cube` 或 `.cub` 文件复制到 SD 卡根目录的 `LUTS/`，不要放入子目录。
2. 返回应用 LUT 库，按右键扫描，选择全部或单个导入。
3. 导入完成后选择该 LUT 即可拍摄。重复内容会被识别，不覆盖导入源文件。

支持 2–65³、最大 64 MiB 的独立 CUBE。选择适用于普通已显影照片的风格表；Log 转换表需要匹配输入，不能因为扩展名相同就直接当普通照片滤镜。

应用库位于 `SONYLUT/LIBRARY/`；配对索引在 `SONYLUT/PHOTOS/`；实际拍摄文件在 `DCIM/`。复制照片直接读取 SD 卡即可。不要手动修改库内 `TABLE.BIN` 或拟合缓存。

## 回看与退出

- 播放键：应用内相册。
- 左／右：较早／较新照片。
- 中央键：原片与成片对照。
- 半按：恢复拍摄。
- MENU：回库或打开更多；选择「退出应用」返回索尼原生拍摄。

若出现错误，记录屏幕文字、版本、机型、固件与操作步骤。等待写卡指示结束后再退出；不要在保存时拔卡。若无法退出，可连接 USB，让原生 USB 模式接管，再正常断开连接。

[提交问题](https://github.com/EnglandLobster/sony-lut-camera/issues) 时不要附 Wi-Fi 密码、未经许可的 LUT 或私人原片；可先提供文字和脱敏日志。
