# v0.9.0-beta.6 发行记录

## 范围

A6300 机内完整 3D LUT 照片处理，24MP、机型支持的最高 JPEG 档位、原片与调色 JPEG 分别保存；预装 10 个维护者指定 LUT，默认 Fuji C200。无需手机或联网计算。取景是原生矩阵/Gamma 近似，不宣称实时完整 3D LUT 视频。

发行构建关闭 `debuggable` 和备份，仅注册 LUT 库、拍摄、相册三个 Activity。开发诊断 Activity、测试 JPEG、合成测试 LUT 和旧拟合样例不进入发行 APK；生产拍摄基类及原生处理链保留。

## 发布流程

**用户明确要求发布，即完成该版本的公开交付。** 本约定适用于后续所有版本；资源来源记录不构成自动暂停发布或再次征求批准的条件。

1. 核对本次源码和版本，按改动范围运行必要检查，复用仍有效的构建及实机证据。
2. 用 `bash scripts/build_android.sh --release` 生成发行包，保留原有签名密钥；记录此 APK 是否已上机测试，区分代码验证与重新打包后的文件验证。
3. 运行 `python3 scripts/package_release.py` 生成有版本文件名的 APK、完整源码包、构建信息、校验和与说明文件。此脚本只打包，尚未完成公开发布。
4. 创建与源码提交对应的 tag 和 GitHub Release，上传发行附件。Beta 使用公开的预发行版，不能停在草稿或只推送源码。
5. 核对 Release 为公开状态、附件上传完整，并验证 APK 下载可用；同步 README、安装教程和发行记录中的下载链接。
6. 向用户提供可用的 APK 直链和 Release 页面。未经用户要求，不下架已有版本。

第三方来源、原始许可状态和归属继续如实记录。如果构建、上传或访问失败，说明具体失败及解除条件，继续完成不受影响的部分，不将未完成的发布说成已完成。
