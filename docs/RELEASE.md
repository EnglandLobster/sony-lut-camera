# v0.9.0-beta.3 发行记录

## 范围

A6300 机内完整 3D LUT 照片处理，24MP EXTRA FINE、原片与调色 JPEG 分别保存；内置示例调色和原色。无需手机或联网计算。取景是原生矩阵/Gamma 近似，不宣称实时完整 3D LUT 视频。

发行构建关闭 `debuggable` 和备份，仅注册 LUT 库、拍摄、相册三个 Activity。开发诊断 Activity、测试 JPEG、合成测试 LUT 和旧拟合样例不进入发行 APK；生产拍摄基类及原生处理链保留。

## 发布状态

- 原始代码许可：维护者选择 GPL-3.0-only。
- Sony 内存配置表：APK 使用的 1,860 字节 `MAP24R1.BIN` 来自 `dependencies.lock.json` 固定的 Sony-PictureEffectPlus 版本；上游没有许可文件，尚未确认该表的公开再分发依据。因此 **APK 暂留草稿，不公开发布**。源码不包含这份外部二进制。
- 发行版的独立构建、包检查和实际安装证据在本页验收记录中更新；不能用开发 APK 的验收替代发行包验收。

## 发布流程

1. 确认工作树改动归属，完成产品、数值、缓存、预览拟合及资源目录测试。
2. `bash scripts/build_android.sh --release`，保留原有签名密钥。
3. 运行 `python3 scripts/package_release.py` 生成有版本文件名的 APK、构建清单、校验和及使用指南。
4. 在 A6300 验证启动、首次资源导入、真实快门拍摄、原片/成片回看、半按恢复和原生退出。发行包测试与普通无开发工具安装应分别记录。
5. 确认所有随包资源的分发状态后，创建与源码提交对应的 tag，发布 GitHub Beta Release 和完整源码。不得把草稿标成已发布。
