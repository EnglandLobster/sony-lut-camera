# v0.10.0

[下载 APK](https://github.com/EnglandLobster/sony-lut-camera/releases/download/v0.10.0/SonyLutCamera-v0.10.0.apk) · [发行页](https://github.com/EnglandLobster/sony-lut-camera/releases/tag/v0.10.0) · [安装教程](USER_GUIDE.md)

code121。签名和包名与 0.9.1 相同，可以直接覆盖安装，导入的 LUT 和照片都保留。从 0.9.0-beta.9 及更早版本升级，仍需先删除旧版，见[升级步骤](USER_GUIDE.md#覆盖更新)。

## 新增

- **手动曝光**：档位跟随机身的 P/A/S/M 转盘；没有转盘的机身按下键，在「曝光模式」里选择。A6300 / A6000 上，P 档两个拨轮调曝光补偿；A 档上拨盘调光圈、控制轮调曝光补偿；S 档上拨盘调快门、控制轮调曝光补偿；M 档上拨盘调光圈、控制轮调快门。转盘在 AUTO、SCN、MR 等位置时按 P 拍摄，屏幕会提示。中央键把曝光补偿归零。
- **ISO 和白平衡**：取景时按右键打开 ISO 列表，左键打开白平衡列表，上下选择、中央键确定、MENU 返回。
- **对焦设置**：按下键打开。「移动对焦点」用方向键或拨轮移动方框，中央键保存；「对焦区域」可选广域、中间、自由点等，选自由点并确定后直接进入移动对焦点；「人脸优先」可开关。每一项按中央键打开选项列表，也可以左右直接切换。
- **对焦确认**：半按合焦后，自由点的对焦框变绿，广域和中间在合焦位置显示绿框，取景左下角亮绿点；相机报告没对上焦时显示「对焦失败」。
- **记住设置**：档位、ISO、白平衡、曝光补偿、各档的光圈 / 快门和对焦设置，下次进入时恢复。退出应用后相机恢复你原来的设置，模式跟随转盘当前位置。[操作说明](USER_GUIDE.md#曝光iso白平衡和对焦)

## 变更

- 取景时左右键不再调曝光补偿，改为打开白平衡 / ISO 列表；曝光补偿用拨轮调。
- 进入拍摄时不再强制切到 P 自动曝光。

## 验证与当前缺口

- 新增手动曝光、按键布局与列表、对焦点与区域、对焦确认、记住与恢复的主机测试，包括相机拒绝写入、对焦点被丢弃、光圈 / 快门只能单档调整、相机拒绝记住的档位等情况。主机产品、拍摄链路、兼容性、回调派发、缓存与拟合套件通过；API10 ARM 模拟器 24 MiB 整套与图形回归通过。发行 APK 签名证书与 0.9.1 相同，DEX035、API10、ARMv5/v7 检查通过。
- A6300 / 固件 2.01 实机：转盘 P/A/S/M 跟随、ISO 与白平衡列表、对焦点移到画面边缘后保存、广域 / 中间 / 自由点的合焦绿框、退出后对焦区域与曝光设置恢复。用户用新控制实拍多组；一次进入应用连续拍摄 42 组，全部成对保存，按快门到保存完成中位 4.2 秒，前 10 张和后 10 张耗时相同，没有张数限制。取景时耗电约每 1.6 分钟 1%（开着测试连接 Wi-Fi），拍照本身额外耗电很少。
- A6300 不允许应用切换到「区」对焦区域，选到时会提示并从列表移除。
- **尚未实机确认**：转盘切换档位后恢复该档上次的光圈 / 快门；人脸优先的实际效果；A6000、A7、A5100 等其他机型上的新控制。这些机型如果进入拍摄报错或拨轮分工不对，请通过 MENU → 导出诊断日志提交 `SONYLUT/DIAG/REPORT.ZIP`。

## 修复了什么

我们在 rc.3 合并通用保存恢复时，错误要求原片先进入索尼索引，才允许保存调色片；索尼可能在两张都完成后才发布索引，从而形成循环等待。PR #2 作者的 API10 动画清理修复没有引入这一保存条件，作者贡献和该修复继续保留。

- 有成功原生回调时，RPC 返回后直接检查指定 JPEG，不再硬等新增索引。
- 回调缺失时由独立索引线程恢复，慢查询不会堵住迟到成功回调；过滤已经确认的原片，支持两张一起晚入库。
- 中途返回仍完成已经声明的双保存，再退出；不提前丢掉第二条记录，不强制释放仍由原生调用持有的图像。
- 区分等待阶段、记录原生状态码和具体错误；空索引水位支持首条记录序号 0。
- LUT 导入兼容根目录 `LUTS` / `LUT` 及目录名大小写变体。

完整 LUT、全尺寸、十个预装 LUT、rc.6 原生内存表选择与签名保持不变。[详细回归分析](compatibility/PAIR_STORE_REGRESSION.md)。

旧版在“第二张后发布索引”的本地模型中复现永久 pending；修复版通过继续/停止 × 最终回调存在/丢失四种组合，以及索引读取挂起、快照挂起、迟到回调、查询数量上限和旧协议提交前失败测试。

最终 APK 已通过 API10 / 24 MiB 整套验证，包括 18 组全尺寸保存链路、4 组保存 RPC 阻塞、跨进程保护、索引故障与 96 轮动画清理。四张已有 Sony 原生 JPEG 的主机校验通过。发行包、源码包及签名检查通过。

**本版 A5100/A6300 真机拍摄回归仍待完成。** 截图和历史 A6300 事件顺序支持这项回归解释，尚未取得本次用户完整日志；没有把每次原生“修复数据”提示都归为已确认的同一底层原因。机型范围见 [Recipe 清单](compatibility/RECIPE_TARGETS.md)。

普通使用后如仍异常，可从更多菜单导出 `SONYLUT/DIAG/REPORT.ZIP`。日志不含照片或 LUT 内容。
