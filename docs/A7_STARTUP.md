# A7 一代准备拍摄退出：修复候选与日志采集

候选版本：0.9.0-beta.6-rc.1 / code97。保留已发布 beta.5 的包名与签名，可覆盖安装。A7 实机根因尚待诊断文件确认，尚未宣布 A7 兼容验收通过。

## 已确认的问题与本轮修改

1. beta.5 的正式拍摄入口沿用了诊断前提：相机必须已经处于单张、JPEG、6000×4000，否则初始化抛错。候选版在打开拍摄会话后临时配置这些字段，验证读回结果，退出时恢复原值；写入部分失败也保留恢复数据。
2. 初始化错误界面只显示“请返回 LUT 库”，关闭资源后的重新进入又会直接结束页面。候选版保留具体阶段与异常，并在返回 LUT 库时显示详情。
3. 诊断从 LUT 预览拟合之前就开始记录；进入独立拍摄进程后记录机型、固件、平台、内存配置、Android SDK、相机参数和最后完成的初始化阶段。即使原生进程退出，已写入的文件也可通过读卡器取得。

这些是源码确认并经主机测试覆盖的问题；它们与用户的准备后退出现象一致，但没有该 A7 的现场日志，尚未确定具体触发条件。保留原有已验证内存布局检查，不向未知布局加载 A6300 的配置表。

## 请反馈用户这样操作

1. 用原来的安装方法覆盖安装这个候选 APK，保持 SD 卡原有内容。
2. 打开应用，选择 Fuji C200，进入拍摄。若再次报错或退出，只需复现一次。
3. 等写卡结束，正常关机，取出 SD 卡，用读卡器复制 `SONYLUT/DIAG/INIT.TXT`。
4. 把这个文件发回，并说明“回到 LUT 库 / 回到索尼原生界面 / 整机重启”中的哪一种。日志自动记录可取得的固件和平台信息，无需用户手动查参数。

每次重新进入拍摄会更新 INIT.TXT，因此复现后先复制文件，再尝试其他 LUT。文件不包含照片、序列号或网络密码。

若用户暂时不换包，beta.5 已有的 `SONYLUT/Rxxxxxxx/PROBE.JSN`（按修改时间找最近一次）和同目录的 `CRASH.TXT`（若存在）也可先用于诊断。

## 验证

主机测试覆盖 RAW+JPEG、连拍和小尺寸的正常配置及恢复、部分写入失败、读回不符、机型不支持所需尺寸、已符合条件时不额外写参数、日志容量上限和新尝试重置。发行包构建和包检查通过。A7 的实际进入拍摄和真实快门结果仍需以上反馈。
