## 画质、取景与恢复

- 固件广告画质 `95,50,25`，启动从原有 FINE（50）自动选择 EXTRA FINE（95）；注册后读回仍为 95，HUD 显示“JPEG EXTRA FINE · 本机最高画质”。
- 两次拍摄后退出、重新进入拍摄页成功。另一次启用近似彩色取景，初始化通过。
- 彩色取景下仅注入 FOCUS（80）按下/松开：先恢复基线并校验，再开放快门，松开后重新启用近似预览。此次没有曝光，全程没有模拟全按快门。
- 三次拍摄会话退出均恢复原画质 FINE、智能变焦和曝光/拍摄设置。临时启用的彩色取景已恢复为用户原来的原色取景，相机停在 LUT 库。
- 观察期间没有拍摄崩溃或相机重启；安装前后与结束时 boot ID 一致。
